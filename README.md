# Foglio Cluedo

Foglio segna-indizi per Cluedo, da usare su telefono o PC.

**Aprilo qui:** https://buldidev.github.io/Foglio-Cluedo/

- Tocca una casella per alternare **✕** (ce l'ha) e **?** (forse)
- Tocca una casella in cima per scrivere i nomi: compaiono le iniziali
- Tocca il nome di una carta per barrarla
- Tutto resta salvato sul dispositivo
